# Gam3ety | جمعيتي

نظام إدارة الجمعيات (الموازير) في مصر.

## المميزات

- 🔍 بحث عن الأعضاء برقم الهاتف
- 📊 لوحة تحكم كاملة
- ➕ إضافة وتعديل وحذف الأعضاء
- 📈 إحصائيات فورية
- 🔐 نظام مصادقة آمن
- 📱 تصميم متجاوب مع جميع الشاشات
- 🌙 دعم الوضع الداكن
- 🎨 واجهة حديثة بتصميم Glassmorphism

## التقنيات المستخدمة

- Node.js
- Express.js
- Firebase Firestore
- JWT Authentication
- Vanilla JS + CSS
- Vercel Deployment
